Mathematical Reference & Live Derivations

Mutual Information
I(X;Y) = H(X) + H(Y) - H(X,Y)

Measures how many bits of uncertainty about X vanish when observing Y. Always non-negative: I(X;Y) ≥ 0.

Conditional Mutual Information
I(X;Y|Z) = H(X|Z) + H(Y|Z) - H(X,Y|Z)

Uncertainty shared between X and Y after learning Z. If I(X;Y|Z) = 0, X and Y are conditionally independent given Z.

Interaction Information / Synergy
I(X;Y;Z) = I(X;Y) - I(X;Y|Z)

Can be positive (Z explains shared redundant information) or negative (synergy / collider: knowing Z reveals relationship unseen separately!).
